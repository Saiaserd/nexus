# 0006：UI 實作基礎（樣式、主題、字型、存檔）

- 日期：2026-10-25
- 狀態：已採用
- 決定者：PM / CTO（D-01、D-02 經作者確認）

## 背景
作者已確認 M1 設計稿（https://claude.ai/artifact/TvyTEzBXdyibRPPXrfGSiH），並選擇**系統原生標題列**（待決事項 D-02 = A）。UI 開工前要先把幾個橫跨所有畫面的技術基礎定下來。

## 決定
1. **樣式基底**：`QStyleFactory::create("Fusion")`，再加上 `QPalette` 與一份集中的 QSS。不用 Windows 11 原生 style，因為它對 QSS 的支援不完整，兩個平台的外觀也會不一致。
2. **色票**：所有顏色集中在 `src/ui/Theme`（淺色、深色兩套），數值以設計稿 `Main.dc.html` 的色票為準。程式其他地方**不准寫死色碼**。
3. **主題切換**：淺色、深色、跟隨系統三種；用 `QSettings` 記住，預設淺色。並呼叫 `QGuiApplication::styleHints()->setColorScheme()`（Qt 6.8），讓原生標題列跟著主題變成深色或淺色。
4. **標題列**：系統原生（D-02 = A）。設計稿中的自繪標題列不做；選單列照設計稿用 QSS 上色。
5. **字型**：
   - 介面與內文：用系統字型。Windows 是 `Segoe UI` + `Microsoft JhengHei UI`；Linux 是 `Noto Sans CJK TC`，沒有就退回系統預設。不內嵌中文字型，因為一套就要數 MB，違反「閒置記憶體 < 150MB」。
   - 等寬：內嵌 JetBrains Mono（OFL 授權，約 300KB），放在 qrc。
6. **圖示**：線條 SVG 放在 qrc，執行時依目前色票上色。不用 emoji，也不用點陣圖。
7. **存檔**：**自動儲存**。停止輸入 1 秒後存檔，切換分頁、關閉分頁、視窗失去焦點、關閉程式時也會存；Ctrl+S 立即存檔。所以設計稿中「未儲存」的圓點只會短暫出現；外部修改衝突列（設計稿狀態 4）只會在這短暫的時間窗裡出現。之後可以在設定中關掉自動儲存。
8. **執行緒**：讀檔、寫檔、開啟 vault 一律用 `QtConcurrent`，結果透過 `QFutureWatcher` 回到 UI 執行緒（CLAUDE.md 規定）。

## 理由
- Fusion 搭配 QSS 在 Windows 與 Linux 的外觀可以預期、也一致，最接近設計稿。
- 色票集中管理，兩套主題才能真正共用同一套版面，日後新增強調色也只要改一個地方。
- 自動儲存是 Obsidian 類工具的使用習慣，也能大幅降低資料遺失和外部修改衝突的機會。
